# طابوني برو — Tabooni Pro · v1.1

موقع/تطبيق ويب (PWA) بالعربي، مصمّم للتلفون أولًا، ينزل على GitHub Pages ويعمل على الدومين `www.taboonipro.com`.

## شو فيه
- 4 شاشات بأسلوب تطبيق: الرئيسية · المنيو · السلة · عنّا (شريط تنقّل سفلي على التلفون، قائمة علوية على الكمبيوتر).
- 13 منتج بأسعار المتجر الحالي (31.10.2026)، بحث + فلترة بالأقسام، بطاقة منتج منبثقة من الأسفل (تسكّر بالسحب لتحت أو زر رجوع).
- سلة محفوظة بالجهاز + شريط سلة عائم + إرسال الطلب عبر واتساب (بعد تعبئة الرقم).
- قابل للتثبيت على شاشة التلفون (أندرويد + آيفون)، يفتح بدون شريط متصفح، ويشتغل حتى بدون إنترنت للصفحات المحفوظة.
- `404.html` يحوّل روابط Shopify القديمة (`/products/...`) للمنيو.

## الإعدادات (أعلى السكريبت في `index.html` — قسم CONFIG)
- `whatsapp: '972526992646'` — كل الطلبات تُرسل لهذا الرقم كرسالة واتساب جاهزة.
- `instagram` / `location` — اختياري، يظهروا بصفحة "عنّا" إذا عبّيتهم.
- أحجام البيتزا بمصفوفة `SIZES` (شخصية 40 · شخصية + 50 · وسط 60). أي منتج فيه `sized:true` بياخذ الأحجام.

## لوحة الإدارة (من v1.21)
الرابط: `taboonipro.com/admin.html` — دخول باسم المستخدم `ayman`.
بتعدّل منها بدون كود: المنتجات (اسم، وصف بمحرّر زي Word، صور، سعر، سعر قبل الخصم، أحجام، قسم، ظاهر/مخفي، مختار)، ترتيب المنتجات، الأسئلة، نصوص الواجهة، شريط إعلان، صور الواجهة، أرقام التواصل، وتغيير كلمة السر.

### تفعيل لمرة وحدة
1. Supabase (مشروع VIP) ← **SQL Editor** ← New query ← الصق محتوى `supabase/setup.sql`.
   قبل التشغيل: بآخر الملف غيّر `ayman@taboonipro.com` للإيميل اللي بتدخل فيه لـ VIP. ← **Run**.
   لازم يطلع بالنتيجة سطر فيه إيميلك.
2. Supabase ← Project Settings ← **API**: انسخ `Project URL` و `anon public key` لملف `config.js`
   (`supabaseUrl` و `supabaseAnonKey`)، وعدّل `loginDomain` حسب إيميل الدخول. **لا تحط أبدًا مفتاح service_role.**
3. ارفع `config.js` على GitHub. خلص — من هون وطالع كل التعديلات من لوحة الإدارة.

بدون الخطوات هاي الموقع بيشتغل عادي من `data.js`، ولوحة الإدارة بتعرض رسالة إنه الربط مش جاهز.

### الحماية
- القراءة عامة للمحتوى الظاهر بس. التعديل ورفع الصور للحساب المسجّل بجدول `site_admins` بس (قواعد RLS).
- زبائن VIP اللي عندهم حسابات بنفس المشروع **ما بيقدروا** يعدّلوا إشي بالموقع.
- الجداول كلها بتبلّش بـ `site_` وما بتلمس جداول VIP.

## التعديل المباشر على الموقع (من v1.23)
الرابط: `taboonipro.com/?edit` (أو زر ✎ بلوحة الإدارة). نفس حساب الأدمن.
- **كمبيوتر:** اضغط Ctrl (⌘ بالماك) + كبسة على أي نص أو صورة.
- **تلفون:** زر «تعديل باللمس» ← كبسة على الاشي ← طفّيه لتتنقّل بالموقع.
- نص: بيصير قابل للكتابة مكانه ← «حفظ» (Enter) أو «إلغاء» (Esc) أو «إخفاء/حذف».
- صورة: رفع صورة بدلها، إضافة صورة، اجعلها رئيسية، حذف.
- وصف المنتج: محرّر بتنسيق (عريض، قوائم...).
- النصوص الثابتة (أزرار، عناوين أقسام) كمان بتتعدّل أو بتنخفي، وبترجعها من «النصوص المخفية».

## الرفع على GitHub Pages
1. أنشئ Repository جديد (مثلاً `taboonipro`) وارفع **كل** الملفات والمجلدات كما هي (بما فيها `CNAME` و `.nojekyll` و `assets/`).
2. Settings → Pages → Source: Deploy from a branch → `main` → `/ (root)` → Save.
3. بنفس الصفحة: Custom domain = `www.taboonipro.com` (ملف CNAME موجود أصلًا).
4. عند مزوّد الدومين (DNS):
   - `CNAME` للاسم `www` → `<اسم-المستخدم>.github.io`
   - 4 سجلات `A` للاسم `@` حسب توثيق GitHub الحالي (185.199.108–111.153)
   - **احذف** سجلات Shopify القديمة لنفس الأسماء.
5. استنّى انتشار الـDNS ثم فعّل **Enforce HTTPS**.
6. افحص كل شي على التلفون — **وبعدها فقط** ألغِ Shopify.

## لازم يتعمل قبل إلغاء Shopify
- **الصور:** صورتين بس مربوطين حاليًا من خوادم Shopify — رح ينكسروا لما يتسكّر الحساب. نزّل صور المنتجات وحطها بـ `assets/` (مثلاً `assets/margherita.jpg`) وغيّر حقل `image` لكل منتج. المنتج بدون صورة بيظهر شعار طابوني برو بداله.
- **أوصاف ناقصة (6 منتجات):** بيتزا كنافه، مارغاريتا، زعتر بالطابون، فوكاتشا، لحمجين، نوتيلا كالزوني. انسخ الوصف من Shopify لحقل `description`.
- **صفحات السياسات** (استرجاع/خصوصية) — راجعها وانقلها إذا بدك تحتفظ فيها.

## تحديثات لاحقة
مع كل تعديل: غيّر `version` بـ CONFIG وغيّر `CACHE` بـ `sw.js` لنفس الرقم (مثلاً `v1.1`) — هيك الزبائن اللي ثبّتوا التطبيق بيستلموا النسخة الجديدة.

## حدود هالنسخة (مقصودة)
- لا يوجد دفع أونلاين ولا قاعدة بيانات. الطلب رسالة واتساب، والسعر النهائي يتأكد منك.
- الأسعار مكتوبة داخل الملف؛ تغيير سعر = تعديل `index.html`.
- الخطوة الجاية الطبيعية: ربط المنيو والطلبات بـ Supabase (نفس قاعدة VIP) مع صفحة أدمن.
